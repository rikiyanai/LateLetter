TECHNICAL NOTES (from anim_J_bounce.py analysis)
  - Uses raw terminal mode (no curses) — direct ANSI escape sequences
  - Alt screen buffer for clean entry/exit
  - SIGWINCH handler for terminal resize
  - Particle system: position + velocity + lifetime per particle
  - Gravity applied per-frame to vertical velocity
  - Collision detection via pre-built normal map (dict lookup)
  - Reflection: v' = (v - 2(v·n)n) * damping
  - Key constants to tune:
    FRAME_S = 0.040     (frame time)
    GRAVITY = 0.08      (acceleration per frame)
    BOUNCE_DAMP = 0.32  (energy retained on bounce)
    FRAG_LIFE = 14      (frames before fragment dies)

IMPLEMENTATION APPROACH FOR LATELETTER
  The garden already uses curses (garden.py). Weather/creature animations
  should integrate as overlay layers:
  1. Background layer: sky gradient, clouds
  2. Plant layer: trees, flowers (with sway frames)
  3. Particle layer: rain, snow, leaves (particle system)
  4. Creature layer: birds, butterflies, fireflies
  5. Special layer: letter-bird (only when authenticated)

  Each layer updates independently at its own cadence:
  - Clouds: every 200-500ms (slow drift)
  - Plants/sway: every 300-500ms
  - Rain/snow: every 40-80ms (fast particles)
  - Creatures: every 100-200ms
  - Fireflies: every 150ms (blink cycle)
